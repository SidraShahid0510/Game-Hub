# Game Hub

  This project was to create an interactive online store to display products from an API endpoint.

![image alt](https://github.com/SidraShahid0510/FED1-PORTFOLIO/blob/main/images/Game-hub.jpg?raw=true)

Game Hub is an interactive online store built using HTML, CSS, and JavaScript. It displays products from a public API and allows users to browse games, view detailed information, filter by category or genre, and manage a shopping basket. The site offers a smooth and user-friendly shopping experience from browsing to checkout.

# Features
- Displays a collection of products fetched from an external API on the homepage, allowing users to explore available games.
- Users can filter products based on category, gender, or genre to easily find games that match their preferences.
- Each product links to a detailed view where users can see more information about the selected game.
- Users can add games to their basket directly from the product listing or details page for a streamlined shopping experience.
- Items in the basket can be removed at any time, giving users full control over their selections.
- A checkout page provides a clear summary of all items in the cart, including quantities and total price.
